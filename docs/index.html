Features

One grid. Every layout.

A compact, native window manager that does one thing well and stays out of your Dock.

Global hotkey, your choice

Toggle the grid from any app with Control-Option-G by default. Record a different shortcut in Settings and see an inline error if it is unavailable.

Click or drag to define a frame

Click one cell to fill it, or drag across several to span a rectangle. A translucent live preview shows where the window will land before you release.

Configurable grid and gap

Choose 1 to 12 columns and rows (6 by 4 by default) and set an edge gap from 0 to 40 points between the window and the screen edge.

Nine editable presets

Left Half, Right Third, Centered Large and more are stored as fractional rectangles you can edit. Apply them from the menu bar with keys 1 to 9 or from the grid footer.

Multi-display aware

Windows land on the screen under your pointer and respect the menu bar and Dock. Placement uses points, so mixed Retina and non-Retina setups behave.

Private and menu bar only

No Dock icon, no account, no network access and no telemetry. Press Esc or click outside to close the grid, and optionally launch at login.

Install

Up and running in a minute.

HoverGridSnap is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download HoverGridSnap-macOS.zip and unzip it.
  2. Move HoverGridSnap.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/HoverGridSnap.app
  4. Grant Accessibility access when prompted, in System Settings → Privacy Security → Accessibility, so HoverGridSnap can move and resize windows.

FAQ

Questions, answered.

Is HoverGridSnap really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub. There are no accounts, subscriptions or paywalls, and an optional Support button links to Ko-fi if you want to chip in.

What permissions does it need?

Only Accessibility, which is how macOS lets an app read the front window and set its position and size. Without it the grid will not open. It does not request Screen Recording, Microphone or Camera access, and the global hotkey needs no extra permission.

Where is my data stored?

Settings and presets are saved locally in the app's UserDefaults on your Mac. Nothing is sent anywhere, because the app has no backend and makes no network connections.

Why is the app not notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to approve it, or build it yourself from source with Xcode.

Was this written by AI?

Yes. HoverGridSnap was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
